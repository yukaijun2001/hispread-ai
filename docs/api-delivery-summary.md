# 前端接口与后端交付说明

本轮目标为把已有Vue界面实际调用接到真实Spring Boot/PostgreSQL业务，并交付可用于服务器的Docker版本。前端生产证据并不包含原站私有后台算法或所有第三方协议，因此实现边界必须区分本地业务、可配置集成和真实外部账户验证。

## 接口对账

- `frontend-api-inventory.json`：Babel读取84个恢复模块的网络封装调用点；418处候选调用，218个明确路径模板。局部变量遮蔽、条件和动态拼接仍需人工核查，不能把所有候选都算HTTP接口。
- `api-route-coverage.json`：明确模板和后端路由逐项匹配，原始表达式、方法、模块及行号保留；手工方法修正记录在scripts/api-manual-contracts.json。路由存在不等于业务验证成功。
- `api-system-audit.json`、`api-finance-audit.json`、`api-resources-audit.json`：动态调用、参数、响应结构、持久化流程、集成依赖和测试按业务域记录。
- `api-integration-test-results.json`：最终完整构建的测试结果。

## 已接入的本地功能

账号/角色/资料/建档、供应商筛选与审核、账号绑定和归属历史、账户变更与审核、项目和品类CRUD、报价历史价格和排名、团队部门与项目范围、NewAPI资料识别预览保存与分配、资源统计及操作记录、代理配置及HTTP/HTTPS/SOCKS5认证、TLS出口检测、日账筛选分组和导出、金额来源、结算预览/单张/批量/调整/确认、付款申请/独立审核/线下凭证登记/到账、汇率版本、运营及财务报表、通知发布撤回与送达记录、配置、审计及本地任务。

系统角色与对象授权沿用security-role-policy-v3；运营仅已分配供应商，成员同时受当前项目和本人/部门范围限制。敏感配置写入后不回显。原有独立付款审核、账户快照、版本冲突和幂等规则不会被新增适配绕过。

## 外部服务如何接通

资源提交、OAuth会话、刷新授权、生命周期、代理替换与批量优先级通过管理员配置的资源上游适配器执行；只有真实HTTP响应及明确状态才更新结果，失败/超时可持久化为FAILED/UNKNOWN，不伪造DELIVERED。协议详见resource-upstream-adapter.md。该适配协议可由自有上游实现，但未声称它就是未公开的原站CCMAX私有协议。

Airwallex/OKX/Binance官方只读连接测试与资金执行分离。已实现显式NATIVE_AIRWALLEX/NATIVE_OKX/NATIVE_BINANCE及既有HISPREAD_PAYOUT_V1中台，包含签名、预检、单次幂等执行、原单查单和Airwallex晚退回冲账。没有使用真实资金凭据或划转真实资金；账户适用性与限制见native-payment-implementation.md。

报价自动续期使用本地新增的显式管理员规则，不猜原站默认规则。选择已通过报价并配置续期天数后，仅生成未来PENDING申请，仍需独立审核；不自动批准。结算截止自动确认是独立本地任务，有持久化执行记录。CCMAX日账/状态采集、优先级轮换与恢复、企业微信提醒已有执行器，按真实配置计算ready；CUSTOM上游仍需兼容服务，企业微信需Webhook和服务端加密密钥。监控已完成定时采集到工作台展示闭环，隔离沙箱不会修改真实账目。

## 服务器交付

生产Compose默认仅ADMIN初始化，不依赖runtime-fixtures、不含演示账号。非root镜像、内部数据库/后端网络、Nginx同源入口、Flyway迁移、PostgreSQL持久会话、上传卷、健康检查、日志轮转、优雅关闭、可选HTTPS边缘和备份恢复脚本都在deploy/README.md中。源代码发布包不含.env、真实数据卷、上传文件或演示fixture。

Docker本地验收包含镜像真实构建、生产空库启动、同源登录/CSRF、数据库可用、后端重启保留会话，以及备份恢复。线上域名、证书签发、服务器容量、真实上游凭据和公网连通性仍需在目标服务器配置与验收。
