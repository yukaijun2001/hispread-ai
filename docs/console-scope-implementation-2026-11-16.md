# 控制台收紧实现与验证

日期：2026-11-16（Asia/Shanghai）。版本：`0.8.125`。基于用户批准的 [控制台审查](console-scope-review-2026-11-16.md) 实现，产品定位继续为上号、账号交付和报价管理。

## 已实现行为

| 模块 | 当前行为 | 保留的边界 |
| --- | --- | --- |
| 付款 | 主流程仅线下申请；资金通道入口关闭；后端关闭通道配置、连接测试、预检、新线上执行及沙箱写入 | 独立审核、真实凭证、金额占用、供应商确认；已有未决款项仍可查询原结果，不重复出款 |
| 金额录入 | 合为“录入应付依据”，在同一表单选择按报价计算或直接金额 | 来源单号防重、报价快照、审核、结算范围 |
| 营业额 | 从工作台移至报表中心折叠的“手工营业额记录” | 仍是独立经营台账，不计入结算应付；折叠时不请求台账 |
| 原生上号 | 新增交付只展示 OAuth，原生直连不请求代理池，不展示 RT/AT/SK | 原会话与 requestKey 重试、明确拒绝与不确定结果区分；按原目标识别已有资源能力 |
| API 文档 | 示例与下载 OpenAPI 升为 `1.2.0`，使用 projectId、固定 requestKey、完整回调或 code#state | 补齐能力查询、原维护操作查询及核对；旧 CUSTOM 凭据/代理路径另行标注兼容范围 |
| 上号统计 | 一个入口展示成功新增、失败、待核对、每日数量和供应商贡献 | 按原成功回执及首次成功时间统计、资源去重、北京时间；关联和重新授权不计新增；供应商/成员/项目/运营范围生效 |
| 系统参数 | 移除退役 RPM/TPM 倍率编辑和请求 | 历史数据保留，旧写接口继续返回 410 |
| 日账导出 | 选择格式与汇总方式后直接生成下载；历史记录为次级入口 | 原请求键重试、文件归属、有效期和访问权限；不再展示虚假的排队、轮询和取消流程 |
| 代理 | 按目标能力展示；原生直连收起入口，已有 CUSTOM 兼容流程保留 | 修复 skipped 数组契约、行号与安全原因、批量上限；已有代理选项返回 supported 并按资源所属供应商过滤 |
| 提示与权限 | 修正 PRO、初始优先级、NewAPI 本地资料和日账金额提示；移除退役监控授权 | 不重新开放网关调权、模型试调用或原生凭据导入 |

成功统计必须有可确认的原创建回执；无原回执的历史资源不会仅因当前状态 ACTIVE 就算作新增。失败和待核对按每个资源的最新未解决结果计数，已成功的资源不再重复计失败。归档或逻辑删除不抹去历史成功交付。

## 升级与历史数据

Docker 生产配置固定关闭线上付款和支付沙箱。已有通道配置留存用于原款项查单，不能创建新出款；旧线上创建请求关闭后可能返回 410/409，查询已有付款应走原记录 GET/核对入口。线下付款上限继续按结算可用金额计算，已付与未决占用不会释放或重复抵扣。

新增 Flyway `V4__console_scope_permissions.sql`，仅移除角色和用户的两个退役监控权限，保留其余授权、自定义角色缩减、业务数据和会话版本。升级无需清库，不改已有管理员密码，不重置资源或账务。
