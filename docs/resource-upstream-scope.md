# 资源上游功能范围

版本 `0.8.124`，2026-11-14。本站负责供应商上号、账号交付与报价管理，上游负责网关请求、路由和容量运维。

| 范围 | 当前行为 |
| --- | --- |
| 接入配置 | 最高管理员维护接入名称、地址、管理凭据、启用和默认接入；检查连接只核验管理身份，不调用模型。新增只提供 CCMAX 和 New API，已有 CUSTOM 配置可继续编辑使用。 |
| OAuth 上号 | 继续从交付和资源流程发起，绑定供应商、项目、报价、限额和原操作；配置页独立 OAuth 已退出。 |
| 已有账号关联 | 保留 CCMAX 账号和 New API 渠道关联；核验真实上游 ID、版本、目标和重复映射，不伪造新交付成功。 |
| 交付查询 | 保留交付回执、原结果核对、租户/成员/项目/运营归属范围与幂等约束。 |
| 账号维护 | 保留授权范围内的启停、凭据刷新、原账号重新授权和安全归档；不确定操作先查询原结果，不能重复提交。 |
| 状态和额度 | 原生单资源查询只读取上游已有账号快照；不调用 `refresh-usage`，不扫描请求日志，不生成每日费用。New API 保持上游配额原始单位。 |
| 可选状态同步 | 沿用默认关闭的交付状态同步，仅更新状态、健康和查询时间；手动目标同步也执行同一轻量路径。保留已有金额和额度历史，不更新费用、每日消费或权重。 |
| 上号政策 | PRO／非 PRO 分类、每日限额、成员/分组分配和首次入库政策保留；首次上号的服务端初始分配值与持续调整网关路由是两个不同职责。 |

退出当前产品的能力：单个/批量调度权重和优先级修改、优先级任务新建/启动/重试、消耗模型额度的 Say Hi/渠道测试、配置页无业务归属的 OAuth、同步并发调参、原生请求日志日费用采集。对应旧写接口返回 `410 UPSTREAM_FEATURE_RETIRED`，包含服务端阻断。

## 升级兼容

- 不删除已有接入、凭据、资源关联、报价、账单或任务记录；无需新数据库迁移。
- 密码/令牌留空保留原值，读取仍不回显；修改地址清除原 HTTP 确认。编辑已有接入不提供类型切换，服务端也拒绝切换，避免原账号映射被另一套协议解释。
- 并发保护改为服务内部固定上限：每目标 2、全局 4。历史调参数据保留，已不参与执行；旧 GET 返回 `managed:true`，PUT 返回 410。该限制不替代已有上号并发和每日限额。
- 配置页保留「历史调度记录」。原生/NEWAPI 未确认任务可只读核对，不重新写权重；未执行的持久化 PREVIEW 不再执行。CUSTOM 缺少只读结果协议，保留查看，需在上游核对。
- 以前自动扶持留下的原值快照仍可由最高管理员显式恢复，作为旧版本清理；不能新增扶持轮次。此次升级不自动恢复或修改真实账号。
- 旧 RT/AT/SK 导入与代理接入不扩大范围，OAuth 仍为原生新增上号方式。

主要兼容接口：

| 接口 | 行为 |
| --- | --- |
| `POST /api/cc-intake/admin/priority/jobs` | 410，不能新建调整 |
| `POST /api/cc-intake/admin/priority/jobs/{id}/start`、`retry` | 410 |
| `GET /api/cc-intake/admin/priority/jobs`、`/{id}` | 查看历史 |
| `POST /api/cc-intake/admin/priority/jobs/{id}/reconcile` | 仅原生/NEWAPI 历史只读核对 |
| `POST /api/resources/{id}/say-hi` | 410 |
| `POST /api/resource-targets/{id}/oauth/link`、`complete` | 410；使用原交付 OAuth 流程 |
| `PUT /api/resource-targets/{id}/sync-settings` | 410 |
| `POST /api/resource-targets/{id}/sync` | 轻量状态同步；New API 使用单资源详情查询 |

## 验证

独立 PostgreSQL 与本地 HTTP 夹具的全量后端回归 206 项通过，覆盖新写入阻断、旧结果只读核对、原账号/目标绑定、OAuth 和交付幂等、角色范围、凭据维护、轻量同步不采集费用。原运维写入测试已替换为停用与历史恢复测试，保留业务测试。

前端类型检查与生产静态构建通过。本地 ego-browser 的 11 项页面检查通过，涵盖新增/编辑保存、凭据留空、HTTP 确认重置、字段校验、原生/渠道详情精简、兼容配置、历史只读页面和手机布局。夹具通过 `python3 scripts/verify-background-config.py --upstream` 启动，使用 `.invalid` 地址和隔离数据库，不请求真实上游、不新上号；结束清理临时服务、数据库和随机登录凭据。
