## 新发现与修复

**问题：已保存导出参数重放被误判冲突。** 页面生成CSV后，读取记录返回的 filter 字段因 PostgreSQL JSONB 排序发生变化；用原type/format/filter/requestKey重放返回409，尽管筛选内容完全相同。记录数仍为1，没有生成重复文件。

原实现以原始 JSON 文本计算指纹，文本顺序不同会产生不同哈希。`0.8.127` 仅修改导出原请求的匹配：同一用户和requestKey下，对已保存的type/format/filter作结构相等比较，忽略对象字段顺序，保留数组顺序及实际值；内容不变返回原文件ID，实际格式或筛选变化仍409。已有旧哈希和未保存哈希的历史文件同样适用；不修改付款、账户或结算快照指纹，不迁移/重写已有文件。

财务契约 `FinanceContractIntegrationTest` 定向 **11项通过，0失败/错误**。新增回归使用真实PostgreSQL JSONB，确认响应字段顺序确实变化，再分别验证新导出、旧哈希和无哈希记录：相同内容返回原ID/原版本/原文件内容，数量不增加；改变格式或日期返回409。临时数据库已删除，后端打包和前端版本构建通过。
